BIRTHDAY WEBSITE - QUICK GUIDE

1. PHOTOS: copy childhood1.jpg, childhood2.jpg, current1.jpg, current2.jpg into the images/ folder
   (or change the filenames at the top of script.js).
2. NAME: open script.js and edit  name: "NAME"
3. MESSAGES: all messages are in the birthdayData block at the top of script.js.
4. MUSIC: put birthday.mp3 (and optionally click.mp3, cut.mp3) in the audio/ folder.
   If missing, a built-in tune and sounds are used. Music starts after tapping the Music button.
5. RUN: open the folder in VS Code, install the "Live Server" extension,
   right-click index.html > Open with Live Server (or just double-click index.html).
6. HOST FREE: drag the whole folder onto https://app.netlify.com/drop
   or upload to GitHub and enable Settings > Pages.
7. SHARE: copy the URL Netlify/GitHub gives you and send it on WhatsApp.
