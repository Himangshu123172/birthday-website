BIRTHDAY WEBSITE - QUICK GUIDE
1. PHOTOS: put childhood1.png, childhood2.png, current1.png, current2.png in the images/ folder.
   (.jpg/.jpeg/.webp also work automatically. Or change the names at the top of script.js.)
2. NAME + MESSAGES + BIRTH DATE: edit the birthdayData block at the top of script.js.
   birthDate (like 2005-01-01T00:00:00) powers the live age counter on page 1. Use "" to hide it.
3. MUSIC (optional): put birthday.mp3 (and click.mp3, cut.mp3) in the audio/ folder.
4. RUN: VS Code > Live Server > Open with Live Server (or double-click index.html).
5. HOST FREE: drag this folder onto https://app.netlify.com/drop, or use GitHub Pages.
6. TIP: shrink photos to under 500 KB (tinypng.com) so they load fast on phones.
